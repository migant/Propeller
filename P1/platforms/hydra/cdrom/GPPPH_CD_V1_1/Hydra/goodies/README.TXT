README.TXT - for \Goodies diretory.

This directory contains various game demos and goodies. 

Also, there is a NEW "user_programs\" sub-directory 
that contains public domain user demos and programs from the HYDRA community, check them out! 

However, please ask permission from the authors before you distribute them. Also, many of them use 
copyrighted drivers from this CD and the HYDRA book, those drivers can't be distributed 
under any circumstances, eg. the HEL graphics engine and the NS sound driver for example.
